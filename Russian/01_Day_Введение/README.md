## Введение в Python


Python — это высокоуровневый язык программирования общего назначения. Это открытый, интерпретируемый, объектно‑ориентированный язык. Python создал голландский программист Гвидо ван Россум. Название языка произошло от британского комедийного сериала «Летающий цирк Монти Пайтона». Первая версия была выпущена 20 февраля 1991 года.


Этот 30‑дневный курс поможет вам шаг за шагом изучить последнюю версию Python 3.


## Почему Python?


* близок к человеческому языку — легко изучать;
* используется в различных отраслях и компаниях (включая Google);
* подходит для веб‑приложений, десктопных приложений, системного администрирования и библиотек машинного обучения;
* популярен в сообществе Data Science и машинного обучения.
