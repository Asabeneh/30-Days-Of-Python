## Модули

### Что такое модуль

Модуль — это файл, содержащий набор кода или набор функций, которые можно включить в приложение. Модулем может быть файл, содержащий одну переменную, функцию или большую кодовую базу.

### Создание модуля

Чтобы создать модуль, мы пишем наш код в python-скрипте и сохраняем его как файл .py. Создайте файл с именем mymodule.py внутри папки вашего проекта. Давайте напишем немного кода в этом файле.

```py
# файл mymodule.py
def generate_full_name(firstname, lastname):
    return firstname + ' ' + lastname
```

Создайте файл main.py в каталоге вашего проекта и импортируйте файл mymodule.py.

### Импорт модуля

Чтобы импортировать файл, мы используем ключевое слово _import_ и только имя файла.

```py
# файл main.py
import mymodule
print(mymodule.generate_full_name('Asabeneh', 'Yetayeh')) # Asabeneh Yetayeh
```

### Импорт функций из модуля

В файле может быть много функций, и мы можем импортировать все функции по-разному.

```py
# файл main.py
from mymodule import generate_full_name, sum_two_nums, person, gravity
print(generate_full_name('Asabneh','Yetayeh'))
print(sum_two_nums(1,9))
mass = 100
weight = mass * gravity
print(weight)
print(person['firstname'])
```

### Импорт функций из модуля с переименованием

Во время импорта мы можем переименовать имя модуля.

```py
# файл main.py
from mymodule import generate_full_name as fullname, sum_two_nums as total, person as p, gravity as g
print(fullname('Asabneh','Yetayeh'))
print(total(1, 9))
mass = 100 
weight = mass * g
print(weight)
print(p)
print(p['firstname'])
```

## Импорт встроенных модулей

Как и другие языки программирования, мы также можем импортировать модули, импортируя файл/функцию с помощью ключевого слова _import_. Давайте импортируем общий модуль, который мы будем использовать чаще всего. Некоторые из распространённых встроенных модулей: _math_, _datetime_, _os_,_sys_, _random_, _statistics_, _collections_, _json_,_re_

### Модуль OS

Используя python-модуль _os_, можно автоматически выполнять множество задач операционной системы. Модуль OS в Python предоставляет функции для создания, изменения текущего рабочего каталога и удаления каталога (папки), получения его содержимого, изменения и определения текущего каталога.

```py
# импорт модуля
import os
# Создание каталога
os.mkdir('directory_name')
# Изменение текущего каталога
os.chdir('path')
# Получение текущего рабочего каталога
os.getcwd()
# Удаление каталога
os.rmdir()
```

### Модуль Sys

Модуль sys предоставляет функции и переменные, используемые для управления различными частями среды выполнения Python. Функция sys.argv возвращает список аргументов командной строки, переданных в скрипт Python. Элемент с индексом 0 в этом списке всегда является именем скрипта, с индексом 1 — аргумент, переданный из командной строки.

Пример файла script.py:

```py
import sys
#print(sys.argv[0], argv[1],sys.argv[2])  # эта строка напечатала бы: filename argument1 argument2
print('Welcome {}. Enjoy  {} challenge!'.format(sys.argv[1], sys.argv[2]))
```

Теперь, чтобы проверить, как работает этот скрипт, я написал в командной строке:

```sh
python script.py Asabeneh 30DaysOfPython
```

Результат:

```sh
Welcome Asabeneh. Enjoy  30DayOfPython challenge! 
```

Некоторые полезные команды sys:

```py
# чтобы выйти из sys
sys.exit()
# чтобы узнать наибольшее целое, которое он принимает
sys.maxsize
# чтобы узнать путь окружения
sys.path
# чтобы узнать версию python, которую вы используете
sys.version
```

### Модуль Statistics

Модуль statistics предоставляет функции для математической статистики числовых данных. Популярные статистические функции, определённые в этом модуле: _mean_, _median_, _mode_, _stdev_ и т. д.

```py
from statistics import * # импорт всех модулей statistics
ages = [20, 20, 4, 24, 25, 22, 26, 20, 23, 22, 26]
print(mean(ages))       # ~22.9
print(median(ages))     # 23
print(mode(ages))       # 20
print(stdev(ages))      # ~2.3
```

### Модуль Math

Модуль, содержащий множество математических операций и констант.

```py
import math
print(math.pi)           # 3.141592653589793, константа pi
print(math.sqrt(2))      # 1.4142135623730951, квадратный корень
print(math.pow(2, 3))    # 8.0, показательная функция
print(math.floor(9.81))  # 9, округление вниз
print(math.ceil(9.81))   # 10, округление вверх
print(math.log10(100))   # 2, логарифм по основанию 10
```

Теперь мы импортировали модуль *math*, который содержит множество функций, помогающих нам выполнять математические вычисления. Чтобы проверить, какие функции есть в модуле, мы можем использовать _help(math)_ или _dir(math)_. Это отобразит доступные функции в модуле. Если мы хотим импортировать только определённую функцию из модуля, мы импортируем её следующим образом:

```py
from math import pi
print(pi)
```

Также можно импортировать несколько функций сразу

```py

from math import pi, sqrt, pow, floor, ceil, log10
print(pi)                 # 3.141592653589793
print(sqrt(2))            # 1.4142135623730951
print(pow(2, 3))          # 8.0
print(floor(9.81))        # 9
print(ceil(9.81))         # 10
print(math.log10(100))    # 2

```

Но если мы хотим импортировать все функции в модуле math, мы можем использовать \* .

```py
from math import *
print(pi)                  # 3.141592653589793, константа pi
print(sqrt(2))             # 1.4142135623730951, квадратный корень
print(pow(2, 3))           # 8.0, показательная функция
print(floor(9.81))         # 9, округление вниз
print(ceil(9.81))          # 10, округление вверх
print(math.log10(100))     # 2
```

При импорте мы также можем переименовать имя функции.

```py
from math import pi as  PI
print(PI) # 3.141592653589793
```

### Модуль String

Модуль string — полезный модуль для многих целей. Пример ниже показывает некоторые способы использования модуля string.

```py
import string
print(string.ascii_letters) # abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ
print(string.digits)        # 0123456789
print(string.punctuation)   # !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~
```

### Модуль Random

К настоящему моменту вы знакомы с импортом модулей. Давайте сделаем ещё один импорт, чтобы как следует с ним освоиться. Давайте импортируем модуль _random_, который даёт нам случайное число между 0 и 0.9999.... В модуле _random_ много функций, но в этом разделе мы будем использовать только _random_ и _randint_.

```py
from random import random, randint
print(random())   # не принимает аргументов; возвращает значение между 0 и 0.9999
print(randint(5, 20)) # возвращает случайное целое число в диапазоне [5, 20] включительно
```
