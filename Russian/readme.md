## Настройка окружения

### Установка Python

Чтобы запускать скрипты на Python, его нужно сначала установить. Давайте [скачаем](https://www.python.org/) Python.
Если у вас Windows, нажмите кнопку, обведённую красным.

[![Установка на Windows](../images/installing_on_windows.png)](https://www.python.org/)

Если у вас macOS, нажмите кнопку, обведённую красным.

[![Установка на macOS](../images/installing_on_macOS.png)](https://www.python.org/)

Чтобы проверить, установлен ли Python, введите в терминале следующую команду:

```shell
python3 --version
```

![Версия Python](../images/python_versio.png)

Как видно в терминале, сейчас я использую _Python 3.7.5_. Ваша версия может отличаться от моей, но она должна быть не ниже 3.6. Если вы видите номер версии — отлично, Python установлен на вашем компьютере. Переходите к следующему разделу.

### Интерактивная оболочка Python

Python — интерпретируемый скриптовый язык, поэтому код не нужно компилировать: он выполняется строка за строкой. Вместе с Python поставляется _Python Shell (интерактивная оболочка Python)_. В ней можно выполнить отдельную команду Python и сразу получить результат.

Оболочка ждёт, когда пользователь введёт код на Python. Когда вы вводите код, она выполняет его и показывает результат на следующей строке.
Откройте терминал или командную строку (cmd) и введите:

```shell
python
```

![Интерактивная оболочка Python](../images/opening_python_shell.png)

Интерактивная оболочка Python открыта и ждёт, когда вы напишете код (скрипт на Python). Код пишется после символов >>>, затем нужно нажать Enter.
Давайте напишем наш самый первый скрипт в оболочке Python.

![Скрипт в оболочке Python](../images/adding_on_python_shell.png)

Отлично, вы написали свой первый скрипт в интерактивной оболочке Python! А как её закрыть?
Чтобы закрыть оболочку, введите после символов >>> команду **exit()** и нажмите Enter.

![Выход из оболочки Python](../images/exit_from_shell.png)

Теперь вы знаете, как открыть интерактивную оболочку Python и как из неё выйти.

Если вы пишете код, который Python понимает, он выдаёт результат, а если нет — возвращает ошибку. Давайте ошибёмся нарочно и посмотрим, что ответит Python.

![Синтаксическая ошибка](../images/invalid_syntax_error.png)

Как видно из сообщения, Python достаточно умён, чтобы понять, какую ошибку мы допустили: _Syntax Error: invalid syntax_ (синтаксическая ошибка: недопустимый синтаксис). Использовать x для умножения нельзя — в Python это недопустимый синтаксис. Вместо (**x**) для умножения используется звёздочка (\*). Сообщение об ошибке ясно показывает, что нужно исправить.

Поиск и устранение ошибок в программе называется _отладкой_ (debugging). Давайте отладим наш код: поставим \* вместо **x**.

![Исправление синтаксической ошибки](../images/fixing_syntax_error.png)

Ошибка исправлена, код выполнился, и мы получили ожидаемый результат. Программист сталкивается с такими ошибками каждый день, поэтому важно уметь отлаживать код. А чтобы хорошо отлаживать, нужно понимать, с какими ошибками вы имеете дело. Вот некоторые ошибки Python, которые могут вам встретиться: _SyntaxError_, _IndexError_, _NameError_, _ModuleNotFoundError_, _KeyError_, _ImportError_, _AttributeError_, _TypeError_, _ValueError_, _ZeroDivisionError_ и другие. Подробнее о разных **_типах ошибок_** в Python мы поговорим в следующих разделах.

Давайте ещё попрактикуемся с интерактивной оболочкой Python. Откройте терминал или командную строку и введите слово **python**.

![Интерактивная оболочка Python](../images/opening_python_shell.png)

Интерактивная оболочка Python открыта. Выполним несколько простых математических операций (сложение, вычитание, умножение, деление, остаток от деления, возведение в степень).

Но сначала, прежде чем писать код на Python, немного посчитаем:

- 2 + 3 = 5
- 3 - 2 = 1
- 3 \* 2 = 6
- 3 / 2 = 1.5
- 3 \*\* 2 = 3 x 3 = 9

В Python есть ещё такие операции:

- 3 % 2 = 1 => остаток от деления
- 3 // 2 = 1 => деление с отбрасыванием остатка

Теперь перепишем эти выражения в виде кода на Python. Оболочка уже открыта — для начала напишем в ней комментарий.

_Комментарий_ — это часть кода, которую Python не выполняет. В комментариях можно оставлять пояснения к коду, чтобы его было легче читать. Комментарий в Python начинается с символа решётки (#).
Вот как выглядит комментарий в Python:

```shell
 # комментарий начинается с решётки
 # это комментарий Python, потому что он начинается с символа (#)
```

![Математика в оболочке Python](../images/maths_on_python_shell.png)

Прежде чем перейти к следующему разделу, ещё немного попрактикуемся в интерактивной оболочке. Закройте её командой _exit()_, откройте снова и попробуйте вводить в ней текст.

![Строки в оболочке Python](../images/writing_string_on_shell.png)

## Основы Python

### Синтаксис Python

Код на Python можно писать в интерактивной оболочке или в редакторе кода. Файлы Python имеют расширение `.py`.

### Отступы в Python

Отступ — это пустое место (пробелы) в начале строки. Во многих языках отступы нужны лишь для того, чтобы код было легче читать, а в Python с их помощью создаются блоки кода. В других языках программирования блоки кода обычно выделяют не отступами, а фигурными скобками. Одна из частых ошибок при написании кода на Python — неправильные отступы.

![Ошибка отступа](../images/indentation.png)

### Комментарии

Комментарии делают код понятнее и позволяют разработчикам оставлять в нём заметки. В Python любой текст после символа решётки (#) считается комментарием и не выполняется при запуске кода.

**Пример: однострочный комментарий**

```shell
    # Это первый комментарий
    # Это второй комментарий
    # Python пожирает мир
```

**Пример: многострочный комментарий**

Для многострочного комментария можно использовать тройные кавычки, если такая строка не присвоена переменной.

```shell
"""Это многострочный комментарий.
Многострочный комментарий занимает несколько строк.
Python пожирает мир
"""
```

### Типы данных

В Python есть несколько типов данных. Начнём с самых распространённых. Подробно каждый тип мы разберём в следующих разделах, а пока просто пройдёмся по ним и познакомимся. Сейчас не обязательно понимать всё до конца.

#### Числа (Number)

- Integer — целые числа (отрицательные, ноль и положительные).
    Пример:
    ... -3, -2, -1, 0, 1, 2, 3 ...
- Float — числа с плавающей точкой (десятичные дроби).
    Пример:
    ... -3.5, -2.25, -1.0, 0.0, 1.1, 2.2, 3.5 ...
- Complex — комплексные числа.
    Пример:
    1 + j, 2 + 4j

#### Строки (String)

Строка — это один или несколько символов в одинарных или двойных кавычках. Для многострочного текста используются тройные кавычки.

**Пример:**

```py
'Asabeneh'
'Finland'
'Python'
'I love teaching'
'I hope you are enjoying the first day of 30DaysOfPython Challenge'
```

#### Логический тип (Boolean)

Логическое значение (boolean) — это либо True, либо False. Буквы T и F всегда пишутся заглавными.

**Пример:**

```python
    True  #  Свет включён? Если включён, значение True
    False # Свет включён? Если выключен, значение False
```

#### Списки (List)

Список в Python — это упорядоченная коллекция, в которой можно хранить элементы разных типов. Список похож на массив в JavaScript.

**Пример:**

```py
[0, 1, 2, 3, 4, 5]  # все элементы одного типа - список чисел
['Banana', 'Orange', 'Mango', 'Avocado'] # все элементы одного типа - список строк (фрукты)
['Finland','Estonia', 'Sweden','Norway'] # все элементы одного типа - список строк (страны)
['Banana', 10, False, 9.81] # элементы разных типов - строка, целое число, логическое значение и число с плавающей точкой
```

#### Словари (Dictionary)

Словарь в Python — это неупорядоченный набор данных в формате пар «ключ — значение».

_Примечание переводчика: начиная с Python 3.7 словари сохраняют порядок, в котором в них добавляли элементы._

**Пример:**

```py
{
'first_name':'Asabeneh',
'last_name':'Yetayeh',
'country':'Finland',
'age':250,
'is_married':True,
'skills':['JS', 'React', 'Node', 'Python']
}
```

#### Кортежи (Tuple)

Кортеж, как и список, — это упорядоченная коллекция элементов разных типов, но после создания кортеж нельзя изменить. Кортежи неизменяемы (immutable).

**Пример:**

```py
('Asabeneh', 'Pawel', 'Brook', 'Abraham', 'Lidiya') # имена
```

```py
('Earth', 'Jupiter', 'Neptune', 'Mars', 'Venus', 'Saturn', 'Uranus', 'Mercury') # планеты
```

#### Множества (Set)

Множество — это коллекция данных, похожая на список и кортеж. Но, в отличие от них, элементы множества не упорядочены. Как и в математике, множество в Python хранит только уникальные элементы.

В следующих разделах мы подробно разберём каждый тип данных Python.

**Пример:**

```py
{2, 4, 3, 5}
{3.14, 9.81, 2.7} # во множестве порядок не важен
```
