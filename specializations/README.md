# Specializations

The 120-day core builds shared Python, systems, networking, secure-development, defensive, investigative, and professional foundations. These tracks add direction without pretending that one language or one short course can replace supervised experience.

| Track | Best fit if you enjoy… | Entry guide |
| --- | --- | --- |
| Blue Team and Detection Engineering | Telemetry, detection rules, triage, and response automation | [Open the track](blue-team/README.md) |
| Application Security | Secure APIs, threat models, testing, and remediation | [Open the track](appsec/README.md) |
| Digital Forensics and Incident Response | Evidence, timelines, investigations, and reports | [Open the track](dfir/README.md) |
| Malware-Analysis Foundations | Safe static analysis and behavioral reasoning | [Open the track](malware-analysis-foundations/README.md) |
| Cloud and DevSecOps | Identity, delivery pipelines, containers, and configuration | [Open the track](cloud-devsecops/README.md) |
| Network Security and Protocol Engineering | Protocols, traffic, services, and monitoring | [Open the track](network-security/README.md) |

Start with one track for ten days. Keep the artifact, retrospective, and questions. Then either deepen that track or try another. The goal is to discover the type of security engineering problems you want to keep solving.
