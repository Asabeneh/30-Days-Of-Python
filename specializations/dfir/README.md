# Digital Forensics and Incident Response

Preserve, process, analyze, and communicate synthetic evidence with repeatable methods.

This is an optional ten-day track after the 120-day core. Use only the supplied fixtures or explicitly authorized training platforms. Each day should follow the same lesson contract as the core: prerequisites, outcomes, runnable code, tests, scope, practice, and a short evidence note.

| Day | Focus |
| ---: | --- |
| 1 | Case management |
| 2 | Chain of custody |
| 3 | Timeline construction |
| 4 | Filesystem artifacts |
| 5 | SQLite and application data |
| 6 | Email and phishing cases |
| 7 | Network evidence |
| 8 | Volatile-data reasoning |
| 9 | Report writing |
| 10 | Reproducible forensic case |

## Entry requirements

Complete the core through Day 120, read [SAFETY_AND_LAB_RULES.md](../../SAFETY_AND_LAB_RULES.md), and be comfortable with Python modules, tests, files, errors, and the relevant systems or network foundations.

## Exit artifact

Finish with a README, threat model, setup instructions, tests, sample evidence, limitations, and a short retrospective. A specialization is a direction for continued supervised practice, not a claim of mastery.
