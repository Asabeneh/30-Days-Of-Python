# Lab Scope

Target: course-provided synthetic data or a local fixture only.

Permitted actions: read, transform, and test the supplied fixture.

Not permitted: public scanning, real credentials, private data, destructive changes, or testing any system outside this directory.

Stop condition: stop if the input is not synthetic or if the activity would affect another system.

Cleanup: remove temporary files and retain only the source code and test evidence requested by the lesson.
