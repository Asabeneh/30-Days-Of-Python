## تعارف

پائتھن عام مقاصد کے لیے استعمال ہونے والی ایک اعلیٰ سطح کی پروگرامنگ زبان ہے۔ یہ اوپن سورس، انٹرپریٹڈ اور آبجیکٹ اورینٹڈ زبان ہے۔ اسے نیدرلینڈز کے پروگرامر Guido van Rossum نے تخلیق کیا تھا۔ اس کا نام برطانوی مزاحیہ سلسلے *Monty Python's Flying Circus* سے لیا گیا۔ اس کا پہلا نسخہ 20 فروری 1991 کو جاری ہوا۔ یہ چیلنج آپ کو پائتھن 3 مرحلہ وار سکھائے گا۔ مواد 30 دنوں میں تقسیم ہے؛ ہر دن کئی موضوعات، آسان وضاحتیں، عملی مثالیں، مشقیں اور منصوبے شامل ہیں۔

یہ چیلنج ان مبتدیوں اور پیشہ ور افراد کے لیے ہے جو پائتھن سیکھنا چاہتے ہیں۔ اسے مکمل کرنے میں 30 سے 100 دن لگ سکتے ہیں۔ ٹیلی گرام گروپ میں فعال شرکت کرنے والوں کے لیے اسے مکمل کرنا نسبتاً آسان ہو سکتا ہے۔

اصل چیلنج عام فہم، گفتگو کے انداز کی انگریزی میں لکھا گیا ہے۔ یہ دلچسپ اور حوصلہ افزا ہے، مگر محنت بھی چاہتا ہے؛ اسے مکمل کرنے کے لیے مناسب وقت مختص کریں۔ اگر آپ دیکھ کر بہتر سیکھتے ہیں تو <a href="https://www.youtube.com/channel/UC7PNRuno1rzYPb1xLa4yktw">Washera</a> یوٹیوب چینل کی ویڈیو اسباق دیکھ سکتے ہیں۔ [بالکل نئے سیکھنے والوں کے لیے پائتھن کی ویڈیو](https://youtu.be/OCCWZheOesI) سے آغاز کریں۔ چینل سبسکرائب کریں، تبصرے اور سوالات لکھیں اور سرگرم رہیں؛ مصنف آپ کی شرکت کو دیکھ سکے گا۔

مصنف اس چیلنج کے بارے میں آپ کی رائے سننا چاہتا ہے۔ اپنے تجربے اور خیالات کا اظہار اس [رابطے](https://www.asabeneh.com/testimonials) پر کر سکتے ہیں۔

## پائتھن کیوں؟

## کام کے ماحول کی تیاری

<a id="day-1-section-6"></a>

### پائتھن انسٹال کرنا

پائتھن اسکرپٹ چلانے کے لیے پائتھن انسٹال ہونا ضروری ہے۔ آئیے اسے [ڈاؤن لوڈ](https://www.python.org/) کریں۔ اگر آپ ونڈوز استعمال کرتے ہیں تو تصویر میں سرخ دائرے والے بٹن پر کلک کریں۔

[![ونڈوز پر انسٹال کرنا](../images/installing_on_windows.png)](https://www.python.org/)

اگر آپ macOS استعمال کرتے ہیں تو اس تصویر میں سرخ دائرے والے بٹن پر کلک کریں۔

[![macOS پر انسٹال کرنا](../images/installing_on_macOS.png)](https://www.python.org/)

یہ جانچنے کے لیے کہ پائتھن انسٹال ہے یا نہیں، اپنے آلے کے ٹرمینل میں یہ کمانڈ لکھیں:

<div dir="ltr">

```shell
python3 --version
```

</div>

![پائتھن کا ورژن](../images/python_versio.png)

تصویر میں مصنف *Python 3.7.5* استعمال کر رہا ہے۔ اصل کورس میں 3.6 یا اس سے بعد کا ورژن استعمال کرنے کو کہا گیا ہے۔ آپ کے پاس مختلف ورژن ہو سکتا ہے۔ اگر ورژن نظر آ رہا ہے تو پائتھن انسٹال ہو چکی ہے؛ اگلے حصے کی طرف بڑھیں۔

<a id="day-1-section-7"></a>

### پائتھن شیل

پائتھن ایک انٹرپریٹڈ اسکرپٹنگ زبان ہے، اس لیے اسکرپٹ چلانے سے پہلے آپ کو اسے الگ سے کمپائل نہیں کرنا پڑتا۔ انٹرپریٹر ہدایات کو چلاتا ہے۔ پائتھن کے ساتھ *Python Shell*، یعنی تعاملی شیل، آتا ہے۔ اس میں ایک کمانڈ لکھ کر فوراً نتیجہ دیکھا جا سکتا ہے۔

پائتھن شیل صارف کے کوڈ کا انتظار کرتا ہے۔ جب آپ کوڈ درج کرتے ہیں تو وہ اسے چلا کر اگلی سطر میں نتیجہ دکھاتا ہے۔ ٹرمینل یا کمانڈ پرامپٹ کھولیں اور لکھیں:

<div dir="ltr">

```shell
python
```

</div>

![پائتھن کا تعاملی شیل](../images/opening_python_shell.png)

اب تعاملی شیل کھل چکا ہے اور آپ کے کوڈ کا منتظر ہے۔ `>>>` کے بعد پائتھن اسکرپٹ لکھیں اور Enter دبائیں۔ آئیے اپنا پہلا اسکرپٹ لکھیں۔

![شیل میں پائتھن اسکرپٹ](../images/adding_on_python_shell.png)

آپ نے اپنا پہلا پائتھن اسکرپٹ لکھ لیا! شیل بند کرنے کے لیے `>>>` کے بعد **exit()** لکھیں اور Enter دبائیں۔

![پائتھن شیل سے باہر نکلنا](../images/exit_from_shell.png)

اب آپ جانتے ہیں کہ تعاملی شیل کیسے کھولنا اور بند کرنا ہے۔

اگر آپ درست پائتھن کوڈ لکھیں تو نتیجہ ملتا ہے، ورنہ خرابی کا پیغام آتا ہے۔ آئیے جان بوجھ کر ایک غلطی کریں اور نتیجہ دیکھیں۔

![نحوی غلطی کا پیغام](../images/invalid_syntax_error.png)

پیغام میں *SyntaxError: invalid syntax* نظر آ رہا ہے۔ ضرب کے لیے `x` استعمال کرنا درست پائتھن نحو نہیں ہے۔ اس کی جگہ ستارہ `*` استعمال ہوتا ہے۔ پیغام بتاتا ہے کہ کوڈ میں کیا درست کرنا ہے۔

پروگرام میں غلطیاں تلاش کرنے اور دور کرنے کے عمل کو *ڈیبگنگ (debugging)* کہتے ہیں۔ `x` کی جگہ `*` لکھ کر اسے درست کریں۔

![نحوی غلطی درست کرنا](../images/fixing_syntax_error.png)

غلطی دور ہو گئی، کوڈ چلا اور متوقع نتیجہ مل گیا۔ پروگرامنگ میں ایسی غلطیاں عام ہیں۔ اچھی ڈیبگنگ کے لیے خرابی کی نوعیت سمجھنا ضروری ہے۔ آپ کو *SyntaxError*، *IndexError*، *NameError*، *ModuleNotFoundError*، *KeyError*، *ImportError*، *AttributeError*، *TypeError*، *ValueError* اور *ZeroDivisionError* جیسی غلطیاں مل سکتی ہیں۔ ان کی تفصیل آگے پڑھیں گے۔

آئیے شیل میں مزید مشق کریں۔ ٹرمینل یا کمانڈ پرامپٹ میں **python** لکھیں۔

![پائتھن شیل کھولنا](../images/opening_python_shell.png)

اب بنیادی حسابی عمل، یعنی جمع، تفریق، ضرب، تقسیم، باقی معلوم کرنا اور قوت نکالنا آزمائیں۔ پہلے حساب کو دیکھیں:

- `2 + 3 = 5`
- `3 - 2 = 1`
- `3 * 2 = 6`
- `3 / 2 = 1.5`
- `3 ** 2 = 3 × 3 = 9`

پائتھن میں یہ عمل بھی موجود ہیں:

- `3 % 2 = 1` — تقسیم کا باقی معلوم کرنا۔
- `3 // 2 = 1` — حاصلِ تقسیم کو نیچے کی طرف قریب ترین صحیح عدد تک لے جانا۔

اب ان حسابی عبارتوں کو پائتھن کوڈ میں لکھیں۔ پہلے شیل میں ایک تبصرہ لکھتے ہیں۔

*تبصرہ (comment)* کوڈ کا وہ حصہ ہے جسے پائتھن ہدایت کے طور پر نہیں چلاتا۔ اس سے ہم وضاحتیں شامل کر کے کوڈ کو پڑھنے میں آسان بناتے ہیں۔ پائتھن میں تبصرہ ہیش `#` سے شروع ہوتا ہے۔ مثال:

<div dir="ltr">

```shell
 # comment starts with hash
 # this is a python comment, because it starts with a (#) symbol
```

</div>

![پائتھن شیل میں حساب](../images/maths_on_python_shell.png)

اگلے حصے سے پہلے کچھ مزید مشق کریں۔ `exit()` لکھ کر شیل بند کریں، دوبارہ کھولیں اور اس میں متن لکھیں۔

![شیل میں سٹرنگ لکھنا](../images/writing_string_on_shell.png)

## پائتھن کی بنیادی باتیں

<a id="day-1-section-11"></a>

### پائتھن کی نحو

پائتھن اسکرپٹ تعاملی شیل یا کوڈ ایڈیٹر میں لکھا جا سکتا ہے۔ پائتھن فائل کی توسیع `.py` ہوتی ہے۔

<a id="day-1-section-12"></a>

### پائتھن میں انڈینٹیشن

انڈینٹیشن سطر کے آغاز میں خالی جگہ کو کہتے ہیں۔ کئی زبانوں میں یہ صرف کوڈ کو پڑھنے میں آسان بناتی ہے، مگر پائتھن میں اس سے کوڈ کے بلاک بنتے ہیں۔ دوسری زبانوں میں اکثر اس مقصد کے لیے گھنگریالی قوسین استعمال ہوتی ہیں۔ پائتھن میں غلط انڈینٹیشن ایک عام خرابی ہے۔

![انڈینٹیشن کی غلطی](../images/indentation.png)

<a id="day-1-section-13"></a>

### تبصرے

تبصرے کوڈ کی وضاحت کرتے ہیں اور ڈویلپر کو نوٹس لکھنے کی سہولت دیتے ہیں۔ پائتھن میں سٹرنگ سے باہر `#` کے بعد آنے والا متن تبصرہ ہوتا ہے اور پروگرام اسے نہیں چلاتا۔

**مثال: ایک سطر کا تبصرہ**

<div dir="ltr">

```shell
    # This is the first comment
    # This is the second comment
    # Python is eating the world
```

</div>

**مثال: کئی سطروں کی وضاحت**

تین اقتباسی نشانوں میں لکھی ہوئی سٹرنگ، اگر کسی متغیر کو نہ دی جائے، وضاحتی متن کے لیے استعمال کی جا سکتی ہے۔ تکنیکی طور پر یہ سٹرنگ ہے؛ بعض جگہوں پر اسے docstring کہتے ہیں۔

<div dir="ltr">

```shell
"""This is multiline comment
multiline comment takes multiple lines.
python is eating the world
"""
```

</div>

<a id="day-1-section-14"></a>

### ڈیٹا کی اقسام

پائتھن میں ڈیٹا کی کئی اقسام ہیں۔ ابھی عام اقسام کا مختصر تعارف لیں؛ ہر قسم کو آگے تفصیل سے پڑھیں گے۔ اس مرحلے پر مکمل مہارت ضروری نہیں، صرف پہچان پیدا کریں۔

<a id="day-1-section-15"></a>

#### اعداد

- صحیح عدد (*Integer*): منفی اعداد، صفر اور مثبت صحیح اعداد، مثلاً `-3, -2, -1, 0, 1, 2, 3`۔
- اعشاری عدد (*Float*): مثلاً `-3.5, -2.25, -1.0, 0.0, 1.1, 2.2, 3.5`۔
- مختلط عدد (*Complex*): مثلاً `1 + 1j` اور `2 + 4j`۔

<a id="day-1-section-16"></a>

#### سٹرنگ

ایک یا زیادہ حروف جو سنگل یا ڈبل اقتباسی نشانوں میں لکھے جائیں، سٹرنگ کہلاتے ہیں۔ کئی سطروں کے متن کے لیے تین اقتباسی نشان استعمال کیے جا سکتے ہیں۔

**مثال:**

<div dir="ltr">

```py
'Asabeneh'
'Finland'
'Python'
'I love teaching'
'I hope you are enjoying the first day of 30DaysOfPython Challenge'
```

</div>

<a id="day-1-section-17"></a>

#### بولین

بولین کی قدر یا تو `True` ہوتی ہے یا `False`۔ ان کا پہلا حرف، `T` اور `F`، ہمیشہ بڑا لکھیں۔

**مثال:**

<div dir="ltr">

```python
    True  #  Is the light on? If it is on, then the value is True
    False # Is the light on? If it is off, then the value is False
```

</div>

<a id="day-1-section-18"></a>

#### لسٹ

پائتھن لسٹ ایک ترتیب وار مجموعہ ہے جس میں مختلف اقسام کی قدریں رکھی جا سکتی ہیں۔ یہ JavaScript کے array سے ملتی جلتی ہے۔

**مثال:**

<div dir="ltr">

```py
[0, 1, 2, 3, 4, 5]  # all are the same data types - a list of numbers
['Banana', 'Orange', 'Mango', 'Avocado'] # all the same data types - a list of strings (fruits)
['Finland','Estonia', 'Sweden','Norway'] # all the same data types - a list of strings (countries)
['Banana', 10, False, 9.81] # different data types in the list - string, integer, boolean and float
```

</div>

<a id="day-1-section-19"></a>

#### ڈکشنری

پائتھن ڈکشنری میں ڈیٹا کلید اور قدر (*key-value*) کے جوڑوں میں رکھا جاتا ہے۔ اصل متن اسے غیر مرتب مجموعہ کہتا ہے؛ پائتھن 3.7 اور بعد کے نسخوں میں اندراج کی ترتیب برقرار رہتی ہے۔

**مثال:**

<div dir="ltr">

```py
{
'first_name':'Asabeneh',
'last_name':'Yetayeh',
'country':'Finland',
'age':250,
'is_married':True,
'skills':['JS', 'React', 'Node', 'Python']
}
```

</div>

<a id="day-1-section-20"></a>

#### ٹپل

ٹپل بھی لسٹ کی طرح مختلف اقسام کی قدروں کا ترتیب وار مجموعہ ہے، مگر بننے کے بعد اس کے عناصر تبدیل نہیں کیے جا سکتے۔ اسے ناقابلِ تبدیلی (*immutable*) کہتے ہیں۔

**مثال:**

<div dir="ltr">

```py
('Asabeneh', 'Pawel', 'Brook', 'Abraham', 'Lidiya') # Names
```

</div>

<div dir="ltr">

```py
('Earth', 'Jupiter', 'Neptune', 'Mars', 'Venus', 'Saturn', 'Uranus', 'Mercury') # planets
```

</div>

<a id="day-1-section-21"></a>

#### سیٹ

سیٹ بھی لسٹ اور ٹپل کی طرح عناصر کا مجموعہ ہے، مگر اس میں عناصر کی مقررہ ترتیب نہیں ہوتی۔ ریاضی کے سیٹ کی طرح، پائتھن سیٹ میں ہر منفرد عنصر صرف ایک بار آتا ہے۔

آگے ہر قسم کو تفصیل سے پڑھیں گے۔

**مثال:**

<div dir="ltr">

```py
{2, 4, 3, 5}
{3.14, 9.81, 2.7} # order is not important in set
```

</div>

<a id="day-1-section-22"></a>

### ڈیٹا کی قسم جانچنا

کسی قدر یا متغیر کی قسم جانچنے کے لیے **type** فنکشن استعمال کرتے ہیں۔ تصویر میں مختلف اقسام دیکھی جا سکتی ہیں:

![ڈیٹا کی اقسام جانچنا](../images/checking_data_types.png)

<a id="day-1-section-23"></a>

### پائتھن فائل

اپنے منصوبے کا `30DaysOfPython` فولڈر کھولیں؛ اگر موجود نہیں تو بنائیں۔ اس میں `helloworld.py` بنائیں۔ اب شیل میں کیا گیا کام Visual Studio Code میں کریں۔

تعاملی شیل بعض نتائج **print** کے بغیر دکھا دیتا ہے، مگر فائل چلانے پر نتیجہ دکھانے کے لیے بلٹ اِن فنکشن `print()` استعمال کریں۔ یہ ایک یا زیادہ آرگیومنٹ لیتا ہے، مثلاً `print('argument1', 'argument2', 'argument3')`۔

**مثال:**

فائل کا نام `helloworld.py` ہے۔

<div dir="ltr">

```py
# Day 1 - 30DaysOfPython Challenge

print(2 + 3)             # addition(+)
print(3 - 1)             # subtraction(-)
print(2 * 3)             # multiplication(*)
print(3 / 2)             # division(/)
print(3 ** 2)            # exponential(**)
print(3 % 2)             # modulus(%)
print(3 // 2)            # Floor division operator(//)

# Checking data types
print(type(10))          # Int
print(type(3.14))        # Float
print(type(1 + 3j))      # Complex number
print(type('Asabeneh'))  # String
print(type([1, 2, 3]))   # List
print(type({'name':'Asabeneh'})) # Dictionary
print(type({9.8, 3.14, 2.7}))    # Set
print(type((9.8, 3.14, 2.7)))    # Tuple
```

</div>

فائل چلانے کے لیے نیچے دی گئی تصویر دیکھیں۔ Visual Studio Code کا سبز بٹن دبائیں یا ٹرمینل میں `python helloworld.py` لکھیں۔

![پائتھن اسکرپٹ چلانا](../images/running_python_script.png)
