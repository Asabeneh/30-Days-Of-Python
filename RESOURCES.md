# Learning Resources

Use resources with a purpose. Read a narrow section, run a small example when possible, and write one observation or question. The links below are selected to support the course rather than replace it. For visual explanations, use the [video-resource standard](VIDEO_RESOURCE_STANDARD.md) and the [timestamped video catalog](VIDEO_RESOURCES.md); every video has a written alternative.

## How to use external resources safely

Do not upload private data, university data, real credentials, or proprietary code to a training platform. Do not scan a platform or website outside its documented lab interface. Record the platform, room, date, scope, and lesson connection in your notes. If a source conflicts with the course, prefer the current primary documentation and open an issue that identifies the disagreement.

## Building a reading habit

For a language question, start with Python's documentation. For a framework or risk category, start with NIST, OWASP, MITRE, or OpenSSF. For a practical challenge, start with a course fixture or an authorized training platform. For a career question, compare the skill you are practising with a NICE work role and then seek supervised experience, not just another list of tools.
