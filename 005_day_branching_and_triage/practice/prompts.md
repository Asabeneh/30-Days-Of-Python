# Day 5 Practice

## Level 1 — Mechanical

Run the starter unchanged. Predict one output before running it. Change one input, run again, and write why the output changed.

## Level 2 — Applied

Create a small function that applies today's idea to a synthetic security record. State the input format, the expected output, and what should happen for malformed input. Add at least three examples.

## Level 3 — Synthesis

Add one edge case and one negative test. Write a short note separating what your program observed from what a human analyst would still need to investigate.
