# Video Source Evidence

## Harvard CS50 Python

Official source: https://cs50.harvard.edu/python/

The official course page describes CS50P as an introduction to programming with Python for students with or without prior programming experience. It explicitly covers functions, variables, conditionals, loops, exceptions, debugging, unit tests, third-party libraries, regular expressions, classes, and file I/O. The page links to the official YouTube playlist and official course materials, including problem sets and a final project. This makes it a Tier 1 source for Days 1–20, especially when the course needs a university-backed alternative to a short tutorial.

## Harvard CS50 Cybersecurity

Official source: https://cs50.harvard.edu/cybersecurity/

The official course page presents an OpenCourseWare cybersecurity course with weekly material, lectures, assignments, and a final project. It is suitable for broad cybersecurity foundations and can support the course's security concepts, account and data protection, systems, software, and threat-modeling phases. The written course page remains the authority if a YouTube timestamp drifts.

## Selection implication

The catalog should promote the official CS50P and CS50 Cybersecurity materials above generic “full course” videos. Generic videos may remain as optional alternate explanations only when their technical scope and timestamps are verified.

## Strongest Python recommendation: Harvard CS50P

Official course page: https://cs50.harvard.edu/python/
Official YouTube playlist: https://www.youtube.com/playlist?list=PLhQjrBD2T3817j24-GogXmWqO5Q5vYy0V

The official playlist exposes a coherent sequence with chaptered lectures: Introduction; Functions and Variables; Conditionals; Loops; Exceptions; Libraries; Unit Tests; File I/O; Regular Expressions; Object-Oriented Programming; and Et Cetera. The individual Lecture 0 page exposes chapter markers for Introduction 0:00, `hello.py` 0:24, Command-line Interface 3:19, Python Interpreter 4:00, Functions, Arguments, Side Effects 5:06, Bugs and Debugging 7:35, VS Code and IDEs 9:54, and Return Values and Variables 12:16.
