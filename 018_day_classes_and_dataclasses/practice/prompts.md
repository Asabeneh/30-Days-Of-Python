# Day 18 Practice

## Level 1 — Mechanical

1. Run the starter unchanged and record its output.
2. Change one input and predict the result before running it.
3. Trigger one expected failure and write down the error type.

## Level 2 — Applied

Build a small synthetic security utility that uses today's idea. State its input format, output, acceptance criteria, and safe scope. Include three normal cases and two rejected cases.

## Level 3 — Creative synthesis

Add an edge case that a beginner might miss. Write a regression test and a short paragraph explaining what your program cannot conclude.
