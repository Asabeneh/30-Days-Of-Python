# Glossary

| Term | Meaning in this course |
| --- | --- |
| Authorization | Explicit permission from an owner to perform a defined action on a defined target. |
| Authentication | Establishing which identity is making a request. |
| Authorization decision | Determining what an authenticated identity is allowed to do. |
| Availability | The property that a system or service is reachable and usable when needed. |
| Baseline | A documented description of expected behavior or configuration used for comparison. |
| Canonicalization | Converting equivalent representations into a chosen standard form before comparison. |
| Confidentiality | Preventing information from being disclosed to unauthorized parties. |
| Detection | A rule or process that identifies evidence of a condition worth reviewing. |
| Evidence | Data preserved with enough context and integrity for another person to inspect it. |
| Hash | A fixed-length digest used to compare data for change; it is not automatically encryption. |
| Indicator | A value or pattern that may help identify an event, such as an address, domain, hash, or filename. |
| Inference | A conclusion drawn from observations; it should include confidence and limitations. |
| Integrity | Confidence that data has not been changed without detection. |
| Least privilege | Giving a process or identity only the permissions required for its task. |
| Parser | Code that translates input text or bytes into structured values under a defined grammar. |
| Residual risk | The risk that remains after a mitigation is applied. |
| Scope | The exact targets, actions, time window, and boundaries allowed in a lab or assessment. |
| Threat model | A structured description of assets, actors, trust boundaries, threats, controls, and assumptions. |
| Trust boundary | A point where data, identity, or control moves between different levels of trust. |
| Triage | Sorting and prioritizing observations for appropriate human review. |
| Virtual environment | A project-local Python environment that isolates installed packages and interpreter settings. |
