# Security Policy

This repository is an educational course. Report unsafe lab instructions, accidentally included credentials or private data, vulnerable infrastructure, or a security flaw in the course tooling privately to the course owner rather than opening a public issue with sensitive details.

## What to include

Describe the affected file or lesson, the smallest reproduction, the expected safe behavior, the observed behavior, and whether any data or system was affected. Remove passwords, tokens, personal information, private logs, and proprietary code from the report.

## Safe handling

Do not test a suspected issue against public systems or a third party. Reproduce only in the supplied local fixture or a system you own. Stop if the issue could cause disruption or expose data. The course owner will decide how to validate, fix, and communicate the issue.

## Scope

The course's example vulnerabilities are intentionally local and educational. A vulnerable fixture is not permission to test a similar pattern against a real application. Use the authorization rules in [SAFETY_AND_LAB_RULES.md](SAFETY_AND_LAB_RULES.md).
